# Blog 07 — More Population, More Prosperity?

This Quarto blog investigates whether population growth translates into greater economic prosperity across the 50 U.S. states. Using annual real GDP and resident-population data from the Federal Reserve Economic Data (FRED) service for 2000–2025, the project separates growth in the size of a state's economy from growth in real GDP per resident. All data processing and visualization are performed in R; the main output is an interactive Plotly chart covering 2001–2025.

This README explains where to obtain the original data, how the datasets are organized, which software and packages are required, and how to reproduce the analysis and figure from the source code.

## Data acquisition and sources

The original data are publicly accessible through FRED, which hosts series from the U.S. Bureau of Economic Analysis (BEA) and the U.S. Census Bureau. You do not need to assemble 100 separate CSV files manually: `code/01_get_raw_data.R` downloads and merges the series using the FRED API.

| Measure | Original source | FRED series ID | Frequency and unit |
|---|---|---|---|
| Real gross domestic product (GDP) | BEA | `<STATE>RGSP` (e.g., [`TXRGSP`](https://fred.stlouisfed.org/series/TXRGSP)) | Annual; millions of chained 2017 U.S. dollars |
| Resident population | U.S. Census Bureau | `<STATE>POP` (e.g., [`TXPOP`](https://fred.stlouisfed.org/series/TXPOP)) | Annual; thousands of persons |

Replace `<STATE>` with a two-letter state abbreviation such as `CA`, `TX`, or `NY`. The script uses R's built-in `state.abb` list, so the analysis covers 50 states, excluding Washington, DC. Its request window is January 1, 2000, through December 31, 2025. The original levels cover 2000–2025, while year-over-year growth rates begin in 2001.

For direct inspection or manual downloads, visit the example series pages above and replace the state abbreviation. See also the [FRED API documentation](https://fred.stlouisfed.org/docs/api/fred/) and [BEA's GDP by state documentation](https://www.bea.gov/data/gdp/gdp-state).

### FRED API key

1. Sign in to FRED and request a personal API key from the [FRED API key page](https://fred.stlouisfed.org/docs/api/api_key.html).
2. Create a file called `.Renviron` in the repository root, with this line (substitute your own key):

   ```text
   FRED_API_KEY=your_actual_fred_api_key
   ```

3. Keep `.Renviron` out of Git. Add it to `.gitignore` if necessary; never upload your API key.
4. Before running the download script, check in R:

   ```r
   readRenviron(".Renviron")
   fredr::fredr_has_key()  # Should return TRUE
   ```

The first R script explicitly reads the root-level `.Renviron`, so no key needs to be pasted into the source code. Downloading requires an internet connection.

## Data structure and definitions

### Raw data: `data/raw/state_rgdp_population_2000_2025.csv`

Each row represents one state–year pair. The downloader merges the two series by `state`, `state_abbr`, and `year` using a full join. With complete coverage, there are 1,300 rows (50 states × 26 years).

| Column | Meaning |
|---|---|
| `state` | Full state name |
| `state_abbr` | Two-letter postal abbreviation |
| `year` | Observation year, 2000–2025 |
| `series_id_gdp` | Source FRED GDP series, such as `TXRGSP` |
| `real_gdp_millions_chained_2017_usd` | Real GDP, millions of chained 2017 dollars |
| `series_id_population` | Source FRED population series, such as `TXPOP` |
| `population_thousands` | Resident population, thousands of persons |

### Processed data: `data/process/state_rgdp_population_2000_2025_processed.csv`

Each row remains one state–year. The second script retains the state code, year, GDP, and population, then calculates these variables within each state in chronological order:

| Column | Meaning |
|---|---|
| `state_abbr` | Two-letter state abbreviation |
| `year` | Observation year |
| `real_gdp_millions` | Real GDP, millions of chained 2017 dollars |
| `population_thousands` | Population, thousands of persons |
| `real_gdp_per_capita` | Real GDP per resident, chained 2017 dollars per person |
| `real_gdp_growth_rate` | Year-over-year real GDP growth rate |
| `population_growth_rate` | Year-over-year population growth rate |
| `real_gdp_per_capita_growth_rate` | Year-over-year real GDP-per-capita growth rate |
| `population_growth_rate_share_of_real_gdp_growth_rate` | Population growth rate divided by total real GDP growth rate |
| `real_gdp_per_capita_growth_rate_share_of_real_gdp_growth_rate` | Per-capita growth rate divided by total real GDP growth rate |

Units and missing values. The processed growth rates are decimal proportions, not percentages (`0.02` means 2%). The plotting script multiplies them by 100 for display. Growth rates are missing for 2000, since there is no 1999 observation in the sample. 

Calculation. Let $Y_{s,t}$ be real GDP and $P_{s,t}$ population for state $s$ in year $t$. Then:

$$
\text{Real GDP per capita}_{s,t}
=\frac{\text{Real GDP}_{s,t}\text{ (millions)}}{\text{Population}_{s,t}\text{ (thousands)}}\times 1{,}000,
\qquad
g_{X,s,t}=\frac{X_{s,t}}{X_{s,t-1}}-1.
$$

The exact GDP growth identity is

$$
g_{GDP}=g_{POP}+g_{PC}+g_{POP}g_{PC}.
$$

Figure 1 stacks population growth and per-capita GDP growth as an approximate decomposition and shows observed total GDP growth as a separate dot. Their difference equals the interaction term; it is not an error in the data.

## Software and dependencies

- R and preferably RStudio (a recent R 4.x release is recommended).
- Quarto CLI to render `BlogPost07.qmd` (not required just to generate the CSVs or HTML chart).
- Pandoc accessible from R for `htmlwidgets::saveWidget(..., selfcontained = TRUE)`; this is commonly provided by RStudio or a separately configured Pandoc installation.
- An internet connection and a personal FRED API key for the download stage.

Install all non-base R packages once:

```r
install.packages(c(
  "here",       # Project-root paths
  "fredr",      # FRED API access
  "readr",      # CSV input/output
  "dplyr",      # Data transformations
  "plotly",     # Interactive visualization
  "htmlwidgets" # Self-contained HTML export
))
```

The code also uses the built-in `datasets::state.name` and `datasets::state.abb`; no Python, SQL, or Stata installation is required. The repository does not provide an `renv.lock` file, so R/package versions are **not pinned**. For a reproducibility record, save `sessionInfo()` alongside your results.

## Reproduce the study

### 1. Get the repository

```bash
git clone https://github.com/RodgersYe/RodgersYe_6400_Blog07.git
cd RodgersYe_6400_Blog07
```

If you received the repository as a ZIP file, extract it and open its root directory instead. Install the required software and R packages, then configure `.Renviron` as described above.

### 2. Execute the scripts in order

Important: Run from the repository root. The first two scripts use `here::here()`; the third script uses relative paths (`data/process/` and `figures/`) and therefore depends on the working directory.

In an RStudio Console opened at the repository root:

```r
getwd()  # Confirm that this is the Blog 07 repository root
source("code/01_get_raw_data.R")  # FRED -> data/raw/
source("code/02_analyze_data.R")  # data/raw/ -> data/process/
source("code/03_make_figures.R")  # data/process/ -> figures/
```

Or from a terminal already in the repository root:

```bash
Rscript code/01_get_raw_data.R
Rscript code/02_analyze_data.R
Rscript code/03_make_figures.R
```

The first script retrieves 50 GDP series and 50 population series, merges them, and writes the raw CSV. The second calculates per-capita GDP, growth rates, and growth-rate ratios. The third creates Figure 1, a year-slider chart with all 50 states, stacked bars for the two growth components, and dots for observed real GDP growth.

To regenerate only the figure, you may run script 3 alone provided that the processed CSV already exists.

For exact historical replication, retain the dated source-data snapshot used for the original post or obtain the corresponding historical data vintage from [ALFRED](https://alfred.stlouisfed.org/), rather than assuming that a current FRED download is immutable.

## Troubleshooting and reproducibility notes

- **FRED key is missing or invalid:** verify `.Renviron` is in the repository root and that `fredr::fredr_has_key()` returns `TRUE`. Do not share the key when asking for help.
- **File not found / wrong `here()` root:** set the working directory to the repository root, then run script 1 before scripts 2 and 3. The correct processed folder is **`data/process/`**, not `data/processed/`.
- **FRED request fails or returns incomplete observations:** check connectivity, request limits, and series availability; inspect the raw CSV before proceeding. The scripts do not implement automatic retry logic.
- **Plotly HTML export fails:** check the `plotly` and `htmlwidgets` packages and make sure Pandoc is available to R.
- **Quarto page is missing the chart or cover:** generate the HTML figure first and confirm that `figures/figure_1_gdp_growth_decomposition_by_state.html` and `BlogPost07Cover.png` exist at the paths referenced by the `.qmd` file.
- **Interpretation:** the analysis is descriptive, not causal. Real GDP per resident measures economic output per person, not household income, median living standards, or individual welfare.
